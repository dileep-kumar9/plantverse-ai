# PlantVerse AI

Integrated Next.js application for plant, soil, land, device and garden intelligence.

## Setup
```powershell
npm.cmd install
```
Create `.env.local`:
```env
GEMINI_API_KEY=your_key
```
Run:
```powershell
npm.cmd run dev
npm.cmd run build
```

## Core routes
`/scan`, `/plants`, `/memory`, `/planner`, `/assistant`, `/translator`, `/devices`, `/marketplace`, `/cart`, `/orders`, `/reminders`, `/community`, `/settings`.

See `docs/FEATURE_STATUS.md` and `docs/INTEGRATIONS.md` for production integrations and limitations.
